# VLA OpenClaw ROS2 本科项目

## 目标

此存储库记录了我关于基于VLA的机器人操作决策、ROS2技能执行、异常检测、重新规划和数据收集的本科项目过程。

## 当前重点

- 运行EL-A3 ROS2控制和数据收集代码库
- 构建一个基本的ROS2数据收集工作流程
- 设计VLA结构化任务输出
- 将VLA风格的规划与ROS2技能执行相连接

## 每周进度

- 第1周：运行EL-A3代码库并收集首个rosbag2数据
- 第2周：构建VLA JSON模式和ROS2技能接口
- 第3周：添加异常检测和重新规划日志
- 第4周：准备演示视频和项目报告

## 仓库结构

- docs/：设计笔记和技术报告
- logs/：每日技术进展
- experiments/: 数据收集事件
- assets/：截图、图表、视频
- scripts/：实用脚本
